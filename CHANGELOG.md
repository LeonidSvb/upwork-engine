## [0.2.0] - 2025-09-27

### Добавлено
- Создан полнофункциональный webhook API endpoint для приема данных от Volna
- Реализована полная интеграция с Supabase для хранения вакансий
- Добавлены таблицы jobs и webhook_batches с детальной структурой
- Реализована автоматическая дедупликация вакансий по volna_project_id
- Парсинг всех полей: бюджет, клиентские данные, навыки, категории
- Сохранение raw JSONB для полного логирования всех данных
- Создан фронтенд на Next.js 15 с App Router и TypeScript
- Интегрирован Tailwind CSS и shadcn/ui компоненты
- Реализована таблица вакансий с Badge, Card, Table компонентами
- Прямые ссылки на Upwork вакансии
- Отображение клиентского ранга, бюджета, навыков, страны
- Создан ADR-0001 для документации решения по локальной разработке
- Настроена локальная разработка через Cloudflare Tunnel
- Добавлен package.json с зависимостями для Vercel deployment
- Создан .env.example с примерами переменных окружения
- Настроена автоматическая интеграция GitHub → Vercel

### Исправлено
- Исправлена структура API routes для Next.js 15 App Router (app/api/webhook/route.js)
- Обновлен формат handler с default export на именованный POST export
- Добавлен правильный service_role ключ Supabase
- Исправлен .gitignore для исключения .next и системных файлов

## [1.0.0] - 2025-01-25

### Добавлено
- Инициализация проекта шаблонов кода
- Создан файл CHANGELOG.md для отслеживания истории изменений

- Настроена структура проекта для хранения шаблонов кода

### Настройка MCP серверов
- Подключен MCP сервер shadcn для работы с компонентами UI
- Настроен MCP сервер GitHub с персональным токеном доступа
- Добавлен MCP сервер filesystem для работы с локальными файлами
- Интегрирован MCP сервер Neon для работы с базой данных
- Установлен MCP сервер n8n для автоматизации воркфлоу

### Безопасность
- Добавлены токены доступа для GitHub API
- Настроены учетные данные для n8n API
- Все конфиденциальные данные хранятся в защищенном конфигурационном файле
