## [0.4.0] - 2025-09-27

### Добавлено
- Полная система AI-анализа вакансий с двухуровневой архитектурой
- Интеграция с OpenAI API (GPT-4o-mini для фильтра, GPT-4o для анализа)
- Таблица ai_prompts для версионированного хранения промптов
- Таблица user_profiles для персонализации анализа (multi-user ready)
- API endpoint /api/jobs/[id]/analyze для запуска анализа по требованию
- Компонент AnalyzeButton с real-time статусами и анимацией
- Библиотека lib/openai.ts для централизованной работы с OpenAI
- Функция runQuickFilter() для Boolean фильтрации (pass/fail + reason)
- Функция runDeepAnalysis() для глубокого scoring и рекомендаций
- Структурированное логирование через winston с ротацией файлов
- Автоматическое логирование всех OpenAI запросов (токены, стоимость, время)

### Изменено
- Расширена таблица jobs полями для AI анализа:
  - filter_passed (boolean) - результат первичного фильтра
  - filter_reason (text) - объяснение решения фильтра
  - filter_processed_at (timestamptz) - время фильтрации
  - ai_analysis (jsonb) - полный результат глубокого анализа
  - analysis_processed_at (timestamptz) - время анализа
- Обновлен интерфейс главной страницы с кнопками AI анализа
- Добавлены индексы для оптимизации запросов по новым полям

### Архитектура
- Модульная система: webhook только сохраняет → отдельный API для анализа
- Раздельные промпты в БД для легкого редактирования без деплоя
- Профили пользователей готовы для мультипользовательского режима
- Версионирование промптов для A/B тестирования и улучшений
